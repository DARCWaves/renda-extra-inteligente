# Projeto Renda Extra Inteligente

Stack oficial:
- Node.js
- Express.js
- EJS
- CSS
- JSON local

Regras obrigatórias:
- Nunca quebrar lógica existente.
- Nunca apagar funcionalidades funcionando.
- Nunca simplificar código crítico.
- Nunca trocar arquitetura atual.
- Nunca misturar bots.
- Nunca colocar tokens no código.
- Sempre usar variáveis de ambiente.
- Sempre preservar SEO.
- Sempre preservar pt-BR.
- Sempre preservar a lógica de negócios atual.
- Nunca modificar bots e deployment simultaneamente.
- Nunca mudar sistemas de cron sem validação isolada.
- Priorizar sempre a estabilidade do sistema sobre a otimização.

Prioridades:
1. Segurança
2. Estabilidade
3. SEO
4. Monetização
5. Performance
6. UX
7. Automação

Protocolo de Alteração (Obrigatório antes de cada modificação):
1. Listar arquivos afetados primeiro.
2. Criar sugestões de backup automático.
3. Explicar o impacto exato da mudança.
4. Explicar o procedimento de rollback (reversão).
5. Analisar riscos e benefícios.
6. Nunca aplicar múltiplas mudanças críticas de uma vez.
7. Separar mudanças de segurança, SEO e arquitetura em fases isoladas.

Nunca:
- criar código Frankenstein
- assumir controle total
- apagar lógica funcional
- inventar dependências sem necessidade
